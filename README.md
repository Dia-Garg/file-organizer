# File Organizer

A simple Python automation script that organizes files in a folder based on file extensions.

## Features
- Automatically creates folders based on file type
- Moves files into their respective folders
- Handles missing folders safely

## How to Run

1. Run the script:
   python file_organizer.py

2. Enter the folder path when prompted.

## Tech Used
- Python
- os module
- shutil module
